# Personal Finance Manager

A simple and responsive Personal Finance Manager web application that helps users track their income, expenses, and overall budget efficiently. The application provides real-time updates of financial data with a clean and interactive user interface.

---

## Features

- Add income and expense transactions
- Automatically calculate total balance
- Display total income and expenses separately
- Dynamic budget calculation and updates
- Responsive and user-friendly UI
- Organized code structure using JavaScript modules
- Local data handling for smooth performance

## Tech Stack

### Frontend Technologies

#### HTML5
- Used to structure the web application
- Creates forms, buttons, layouts, and content sections
- Provides semantic structure for better accessibility

#### CSS3
- Used for styling and responsive design
- Handles layouts, spacing, colors, animations, and UI appearance
- Makes the application visually attractive and mobile-friendly

#### JavaScript (Vanilla JS)
- Core functionality of the project
- Handles budget calculations and transaction logic
- Updates UI dynamically without page refresh
- Manages income and expense data

---

## JavaScript Modules Used

### budgetController.js
Responsible for:
- Managing income and expense data
- Calculating totals and budget
- Storing transaction details

### uiController.js
Responsible for:
- Updating UI elements dynamically
- Displaying transactions on screen
- Managing user interaction visuals

### controller.js
Responsible for:
- Connecting business logic and UI
- Handling event listeners
- Controlling overall application flow

### library.js
Responsible for:
- Utility/helper functions
- Reusable methods across the project

## Installation and Setup:

### 1. Clone the repository:
```bash
git clone https://github.com/jyotijena11/Personal-Finance-Manager.git
```

### 2. Move into the project folder:
```bash
cd Personal-Finance-Manager
```

### 3. Install dependencies:
```bash
npm install
```

### 4. Start the development server:
```bash
npm run dev
```

## Available Scripts:

```bash
npm run dev      # start local development server
npm run build    # create production build
npm run preview  # preview the production build locally
